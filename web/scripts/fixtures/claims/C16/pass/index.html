Freezing a system app

Thor normally disables a system app in place and keeps its data files. Root and Dhizuku do not use current-user removal as a freeze fallback.

Shizuku can remove a system app for the current Android user only if Android refuses to disable it and the separate removal fallback setting is enabled. The setting starts enabled but can be switched off before a freeze. Unfreeze then reinstalls the package if it remains on the system partition, though accounts managed by the removed app can still be affected.
