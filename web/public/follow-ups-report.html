#1 NEXT PICK

Home Bento "Restore a Backup" Entry Point

Impact: 4.8 / 5.0 Effort: ≈ 0.5 Days Zero New Strings

Restore currently requires 4 taps deep in Settings (6th category) and is completely hidden for unprivileged users. Adding a RESTORE tile to the Home bento unlocks full discoverability for .thorbak archives, reuses existing translated strings in 8 locales, and requires no schema or ViewModel changes.

Target: MainScreen.kt / HomeActionRow Band C #31
#2 QUICK WIN

Samsung My Files Intent Diagnostic & Direct MIME

Impact: 4.0 / 5.0 Effort: ≈ 1 Hour Issue #161

Band A #10 added an opt-in toggle on AnyFileInstallerAlias. Running one ADB diagnostic command on Samsung hardware to capture the exact MIME type returned by Samsung's MediaStore provider will allow adding a single targeted manifest string, permanently solving APK installs without requiring the broad opt-in toggle.

Target: AndroidManifest.xml Issue #161
#3 UX CLARITY

Differentiate Snowflake Button Action Labels

Impact: 3.5 / 5.0 Effort: ≈ 2 Hours 2 Strings

The snowflake button currently shares one label across two distinct behaviors: Apps tab removes watchlist row (leaves app frozen), while Freezer tab removes row AND thaws. Adopting Option 1 by setting distinct action labels ("Remove & Restore" on Freezer vs "Remove from Freezer" on Apps) eliminates user surprise.

Target: AppActionRow.kt Tier 3 Follow-Up
#4 HYGIENE

Fix 43 SyntheticAccessor Warnings in :app

Impact: 3.0 / 5.0 Effort: ≈ 1 Hour DEX Optimization

Following the successful fix of 18 SyntheticAccessor warnings in :bypass (Band A #12), widening Companion methods from private to internal across :app eliminates 43 synthetic bytecode bridges, reducing APK method count against the 64K limit.

Target: app/src/main/java Static Analysis
