Thor is an open-source Android app manager, app freezer and system app uninstaller. Browse installed apps, freeze apps, debloat with safety guidance, install APK bundles and manage multiple apps at once. Root, Shizuku or Dhizuku enables privileged actions; you can browse and search apps without granting any of them.

FREEZE APPS AND DEBLOAT
• Freeze and unfreeze user or system apps while retaining their data. The method depends on your privilege mode and device.
• Keep track of frozen apps in the Freezer, and group actions with Freeze Profiles.
• Review Universal Android Debloater (UAD) recommendations before changing system apps. Thor blocks Unsafe freeze targets and warns about Expert targets.
• Uninstall a system app for the current Android user when supported, or restore an app whose package remains on the device. This does not remove the system APK from the device partition.

MANAGE AND INSTALL APPS
• Search, sort and filter user and system apps by source, state and permissions. Inspect app details and export your app list to CSV.
• Install APK, APKM, APKS and XAPK packages, including supported OBB assets. Export and share installer bundles.
• Run supported batch actions such as freeze, unfreeze, uninstall, reinstall, suspend, force stop and cache clearing.
• Manage supported runtime permissions, App Ops and app components where your privilege mode allows it.
• Back up and restore supported app bundles. Root is required to include private app data.

DO I NEED ROOT?
No. Shizuku and Dhizuku provide alternative privileged modes, though each needs separate setup. Without a privileged mode, Thor can still browse, search and filter installed apps. Some actions, including private app-data backup, require Root; available actions vary by mode and Android device.

PRIVATE BY DESIGN
Thor is free software under GPL-3.0-or-later, with no ads, analytics or trackers. The optional Extension Manager uses the network to fetch a catalog and verified extensions; the Play build also supports optional purchases through Google Play Billing. Core app-management tools work offline.
